# Guion de video de demostración

Duración sugerida: 4 a 6 minutos.

## 1. Introducción

Presentar el Sistema de Voluntariado UNIFRANZ y su propósito: organizar actividades, registrar participaciones, emitir certificados y administrar donaciones.

## 2. Inicio de sesión y roles

Mostrar el acceso con una cuenta de administrador. Explicar que los estudiantes usan el sistema para consultar actividades y que los administradores gestionan la plataforma.

## 3. Funciones de estudiante

Mostrar la lista y calendario de actividades, el detalle de una actividad, la inscripción y el perfil. Mencionar habilidades, recomendaciones y ranking.

## 4. Funciones administrativas

Mostrar el panel administrativo. Recorrer gestión de usuarios, actividades, solicitudes de participación, certificados, donaciones y registros de acceso.

## 5. Chatbot Ollama

Abrir el botón “Ayuda del sistema”. Realizar una pregunta sobre cómo inscribirse en una actividad o cómo consultar certificados. Explicar que Ollama se ejecuta localmente y que el asistente solo responde preguntas del sistema.

## 6. Arquitectura y cierre

Mostrar la diapositiva de arquitectura de tres capas. Explicar: interfaz Blade/Vite, lógica Laravel y MySQL. Cerrar con el enlace del repositorio GitHub y los documentos de entrega.
